# Дизайн: request-filters-ui

## Контекст

Экран списка заявок уже показывает таблицу и пагинацию. Фича добавляет панель фильтров и передачу параметров в запрос.

## Решения

| Решение | Почему |
|---|---|
| Состояние фильтров хранится в адресной строке (query-параметры), а не в локальном состоянии | требование FFRD: фильтры не теряются при обновлении, ссылкой можно поделиться |
| Отдельный хук работы с фильтрами читает и пишет query-параметры | компоненты панели остаются простыми |
| Запрос списка использует сгенерированный по контракту Store клиент | расхождение с контрактом ловит сборка |
| Проверка периода выполняется до отправки запроса | требование FFRD: запрос с неверным периодом не уходит |
| Любое изменение фильтра сбрасывает страницу на первую | требование FFRD |

## Риски

- Рассинхрон адресной строки и состояния при быстрых изменениях фильтров. Закрывается единственным источником правды: адресная строка.

## Миграция

Не требуется.
