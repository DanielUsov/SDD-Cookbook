# Модуль «Заявки»: backend (актуально)

## Список заявок

- Операция `GET /requests` возвращает страницу заявок.
- Параметры: `page` (с 1) и `size` (по умолчанию 20, не более 100).
- Сортировка: по дате создания, новые первыми.
- Ответ содержит список заявок и признак наличия следующей страницы.

## Ошибки

- Некорректные `page` или `size` дают ответ `400`.
