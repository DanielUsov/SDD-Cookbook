# Матрица чтения: backend

Инструкция для агента и разработчика backend. Поведение по умолчанию: читать только файлы своей области, чтобы не тратить контекст.

Папку фичи ищите по `store-feature` из `proposal.md` change, на пинованном теге Store.

| Файл | Читать |
|---|---|
| `FRD.md` | да |
| `BFRD.md` | да |
| `FFRD.md` | нет |
| `contracts/api.yaml` | да (вместе с `specs/<модуль>/contracts/api.yaml` на том же теге: вместе они дают полный контракт) |
| `contracts/data-model.yml` | да |
| `contracts/integrations.*` | да |
| `specs/<модуль>/` для модулей из таблицы `FRD.md` | да |
| `business-requirements/BRD-*.md` | только если разработчик прямо попросил |

Это поведение по умолчанию. Разработчик может дать агенту прямую инструкцию прочитать что-то ещё, это разрешено.
