# Модуль «Заявки»: frontend (актуально)

## Экран «Список заявок»

- Таблица с колонками: номер, название, статус, исполнитель, дата создания.
- Внизу пагинация: предыдущая и следующая страница.
- Состояния: загрузка, список, ошибка загрузки с кнопкой «Повторить».
- Пустой список показывает сообщение «Заявок пока нет».
