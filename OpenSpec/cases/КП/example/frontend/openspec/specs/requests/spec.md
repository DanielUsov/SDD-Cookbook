# requests: frontend (локальный master spec)

> Реализация и общее поведение frontend для модуля «Заявки». Состояние до фичи HRPPRBCI-XXXX.

## Requirements

### Requirement: Экран списка заявок

Приложение SHALL показывать список заявок таблицей с пагинацией и состояниями загрузки, пустого списка и ошибки.

#### Scenario: Ошибка загрузки
- **WHEN** сервер вернул ошибку при загрузке списка
- **THEN** экран показывает сообщение и кнопку «Повторить»

## Реализация

- Экран собран из компонентов таблицы и пагинации.
- Данные списка загружаются через клиент, сгенерированный по контракту Store.
- Номер страницы хранится в адресной строке.
