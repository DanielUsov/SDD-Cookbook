# Здесь лежал бы Store (git submodule)

В реальном репозитории сервиса папка `openspec/store/` — это git submodule: полная копия Store, закреплённая на теге.

В этом примере Store показан отдельной папкой [store](../../../store/). Пин в данный момент: тег фичи `HRPPRBCI-XXXX/v1`.

После архивации фичи на feature freeze разработчик перепинивает submodule на тег релиза Store (например, `2.4.0`).
