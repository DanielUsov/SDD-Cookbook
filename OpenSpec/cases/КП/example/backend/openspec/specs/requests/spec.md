# requests: backend (локальный master spec)

> Реализация и общее поведение backend для модуля «Заявки». Состояние до фичи HRPPRBCI-XXXX.

## Requirements

### Requirement: Постраничный список заявок

Сервис SHALL возвращать заявки постранично, новые первыми.

#### Scenario: Первая страница по умолчанию
- **WHEN** клиент запрашивает список без параметров
- **THEN** сервис возвращает первую страницу размером 20 элементов
- **AND** признак `hasNext` показывает наличие следующей страницы

#### Scenario: Некорректный размер страницы
- **WHEN** клиент передаёт `size` больше 100
- **THEN** сервис возвращает ошибку `400`

## Реализация

- Контроллер `RequestController` принимает параметры и делегирует в `RequestService`.
- Выборка идёт через репозиторий `RequestRepository` с постраничной выдачей.
- Правила доступа применяются в сервисном слое до выборки.
